# Vision-RTK 2

Advanced sensor fusion combining GNSS, visual odometry, and IMU for precise positioning in GNSS-degraded areas.

## Specifications

| Parameter | Value |
|-----------|-------|
| Sensors | 2x Multi-band RTK GNSS + Visual Odometry + IMU |
| Technology | xFusion (deep sensor fusion) |
| Sensor Input | GNSS, VIO, Wheelspeed, IMU |
| Output | Global position, orientation, velocity with covariance |
| Interfaces | Ethernet, Wi-Fi |

## Features

Real-time positioning, GNSS-denied area capability, visual odometry for drift compensation, dual GNSS receivers for heading
