# MicroStrain 3DM-GX5-AR IMU/VRU

![3DM-GX5-AR](https://media.hbkworld.com/transform/34d7211d-64af-4ffe-94c3-63ea53e82c15/3DM-GX5-SMALL-Product-Photo?io=transform:fill,width:1024&quality=80)

The 3DM-GX5-AR is a compact, automotive-grade IMU/VRU designed for stabilization, mobile robotics, antenna pointing, and platform attitude estimation. It integrates a fully calibrated and temperature-compensated 3-axis accelerometer and 3-axis gyroscope with an onboard adaptive EKF for low-latency orientation output.

## Technical summary

- IMU sampling rate: up to 1000 Hz
- EKF output rate: up to 500 Hz
- Gyro performance: 8 deg/hour in-run bias (-40 to +85 C), ARW 0.3 deg/sqrt(hour)
- Pitch/roll accuracy: +/-0.25 deg static, +/-0.4 deg dynamic
- Accelerometer noise density: 25 ug/sqrt(Hz) (8 g option), 80 ug/sqrt(Hz) (20 g option)
- Interfaces: USB and RS-232 (up to 921600 baud)
- Operating temperature: -40 to +85 C
- Package: CNC anodized aluminum, 36.0 x 36.6 x 11 mm, 16.5 g

## Notes

- IMU and EKF outputs are independently configurable.
- Uses MIP protocol for efficient bandwidth usage.
- Configuration, visualization, and logging are supported through SensorConnect/InertialConnect tools.
