# Ouster Lidar Sensors

## OS2 - Long-Range Lidar

### Specifications

| Parameter | Value |
|-----------|-------|
| Range at 10% | 200 m |
| Max Range | 400 m |
| Vertical FOV | 22.5° |
| Channels | 128 |
| Max Points/sec | 2.62 M |
| Frame Rate | 20 Hz |
| Precision | ±2 cm |
| MTTF | ≥250,000 hrs |
