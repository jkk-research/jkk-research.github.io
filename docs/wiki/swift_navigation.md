# Duro

Ruggedized RTK GNSS+INS receiver with centimeter-level accuracy and military-grade durability.

## Specifications

| Parameter | Value |
|-----------|-------|
| Accuracy (RTK) | 1 cm + 1 ppm |
| Accuracy (SBAS) | 0.5 m |
| IP Rating | IP67 |
| Interfaces | RS-232, Ethernet |

## Features

Centimeter-level RTK accuracy, continuous INS positioning, IP67 rated, M12 connectors
