# VN-310

Tactical-grade Dual Antenna GNSS-Aided Inertial Navigation System with dual multi-band GNSS receivers and integrated IMU.

## Specifications

| Parameter | Value |
|-----------|-------|
| Sensors | Dual L1/L2/E5b GNSS + 3-axis Accel + 3-axis Gyro + 3-axis Magnetometer |
| Data Rate | 400 Hz (Navigation), 800 Hz (IMU) |
| Heading Accuracy | 0.05°-0.1° (INS), 0.3° (GNSS-Compass 1m) |
| Pitch/Roll | 0.015° (Dynamic) |
| Position Accuracy | 1.0 m (Horizontal), 1.5 m (Vertical) |
| RTK Accuracy | 1 cm + 1 ppm CEP |
| Rating | IP68, DO-160G, MIL-STD compliant |
