# Fixposition Vision-RTK 2 Datasheet (Short)

![Vision-RTK 2](https://www.fixposition.com/cdn/shop/files/PBx-A1_side_large.png?v=1774253903)

## Technical specifications

| Parameter | Specification |
|---|---|
| Sensor fusion stack | xFusion |
| Sensor set | Dual multi-band RTK GNSS + visual odometry + IMU |
| Sensor inputs | GNSS, VIO, wheel speed, IMU |
| Outputs | Global position, orientation, velocity, covariance |
| Heading support | Dual GNSS heading |
| Interfaces | Ethernet, Wi-Fi |
| Target use | High-accuracy localization in GNSS-degraded environments |
