## Technical specifications

| Parameter | Specification |
|---|---|
| Sensor type | Digital lidar |
| Wavelength | 1550 nm (eye-safe IR) |
| Primary use | Long-range perception for highway autonomy |
| Output class | High-resolution 3D point cloud |
| On-device processing | Integrated signal processing |
