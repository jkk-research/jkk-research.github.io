# MicroStrain 3DM-GX5-AR IMU/VRU

![3DM-GX5-AR](https://media.hbkworld.com/transform/34d7211d-64af-4ffe-94c3-63ea53e82c15/3DM-GX5-SMALL-Product-Photo?io=transform:fill,width:1024&quality=80)

## Technical specifications

| Parameter | Specification |
|---|---|
| Sensor class | IMU/VRU with triaxial accelerometer + triaxial gyroscope |
| IMU sampling rate | Up to 1000 Hz |
| EKF output rate | Up to 500 Hz |
| Gyro in-run bias | 8 deg/hour (-40 to +85 C) |
| Gyro ARW | 0.3 deg/sqrt(hour) |
| Pitch/roll accuracy | +/-0.25 deg static, +/-0.4 deg dynamic |
| Accelerometer noise density | 25 ug/sqrt(Hz) (8 g), 80 ug/sqrt(Hz) (20 g) |
| Interfaces | USB, RS-232 (up to 921600 baud) |
| Operating temperature | -40 to +85 C |
| Housing | CNC anodized aluminum |
| Dimensions | 36.0 x 36.6 x 11 mm |
| Weight | 16.5 g |
| Protocol/software | MIP protocol, SensorConnect/InertialConnect |
