# NovAtel PwrPak7 Datasheet (Short)

![PwrPak7](https://docs.novatel.com/OEM7/Content/Resources/Images/HomePage/PwrPak7Family.png)

## Technical specifications

| Parameter | Specification |
|---|---|
| Dimensions | 147 x 125 x 55 mm |
| Weight | 500 g |
| Power consumption | 1.8 W |
| Internal storage | 16 GB |
| GNSS constellations | GPS, GLONASS, BeiDou, Galileo, NavIC, QZSS |
| Interfaces | RS-232, RS-422, USB, Ethernet, CAN, IMU, Event I/O |
| RTK accuracy | 1 cm + 1 ppm |
| DGPS accuracy | 0.4 m |
| Single-point L1/L2 accuracy | 1.2 m |
