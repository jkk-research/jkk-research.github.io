# VectorNav VN-310 Datasheet (Short)

![VN-310](https://www.vectornav.com/images/default-source/applications/vn-310_side-by-side_large.png?sfvrsn=80b30031_1)

## Technical specifications

| Parameter | Specification |
|---|---|
| Sensor set | Dual L1/L2/E5b GNSS + 3-axis accelerometer + 3-axis gyroscope + 3-axis magnetometer |
| Navigation update rate | 400 Hz |
| IMU update rate | 800 Hz |
| Heading accuracy | 0.05 to 0.1 deg (INS), 0.3 deg (GNSS compass, 1 m baseline) |
| Pitch/roll accuracy | 0.015 deg dynamic |
| Position accuracy | 1.0 m horizontal, 1.5 m vertical |
| RTK accuracy | 1 cm + 1 ppm CEP |
| Environmental/compliance | IP68, DO-160G, MIL-STD class compliance |
